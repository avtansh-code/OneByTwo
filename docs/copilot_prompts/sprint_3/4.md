STANDING CAVEATS (read first)
────────────────────────────────────────

- **The four invariants are untouched and re-affirmed.** (1) **Money is integer paise** — the segmented split-method control and every amount surface render only via `formatInrFromPaise()`; no `paise / 100`; any amount-entry keeps an `onChanged(int paise)` contract. (2) **`simplifiedBalances` is server-written / client-read-only** — the **balance pill** and the **settle-up bottom sheet READ the projection only** and show the **single** suggested payment (recipient + amount); **never a who-paid-whom debt graph** (rendering a debt web, or wiring the UPI slot live, is a blocking defect). (3) **OS system share sheet only.** (4) **Single Firebase project; pre-merge testing on the Emulator Suite.** Any item that weakens one is a blocking defect — refuse and cite the invariant.
- **Balance signal = colour + icon + label, never colour alone (§B.3).** The shared `OBTBalancePill` MUST render the trio: positive → `balancePositive` + `arrow_upward` + "you are owed"; negative → `balanceNegative` + `arrow_downward` + "you owe"; zero → `balanceZero` + `check` + "Settled up". A widget test must independently find the **icon** and the **text label** (not read colour to prove intent) and assert the colour branch; the **colour-only negative case must be asserted to FAIL**.
- **`onPrimary` is INK, never white.** Primary affordances (CTA buttons, the success-moment, any marigold fill) take **ink** `onPrimary`. White on marigold ≈ 2.5:1 fails AA and is the DC-01 contrast-gate negative case.
- **Inert extension slots ship present but disabled.** The settle-up sheet's **"Pay via UPI"** row is **present, tagged "Coming soon", labelled, and announced as disabled** — **not wired** (§5). (The add-expense "Make recurring" toggle and Profile "Language" row are screen-level, DC-10/step-3 — not this PR.)
- **Components in ISOLATION — no screen conversion.** Build each as a reusable shared widget with its four states and goldens; do **not** convert, wire, or re-route any screen (that is DC-04+). Do **not** build the two Groups components (#10 group segmented tab bar, #12 stacked-avatar cluster) — deferred to Sprint 4; record the deferral.
- **No hard-coded Haldi hex at component call sites.** All colour via `Theme.of(context).colorScheme` / `OBTColors`; all type via `theme.textTheme` / `OBTText`; all radii via the `AppTheme` scale; category hues via `OBTColors.category` / `categoryColor`. `theme.dart` / `core/theme/*` remain the single source of truth — consume, do not edit.
