STANDING CAVEATS (read first)
────────────────────────────────────────

- **The four invariants are untouched and re-affirmed.** (1) Money is integer paise — amounts are rendered **only** via `formatInrFromPaise()`; `OBTText.amount*` restyles the *display* (Bricolage tabular figures) but never introduces `paise / 100` arithmetic. (2) `simplifiedBalances` stays server-written / client-read-only — this PR touches no projection. (3) OS system share sheet only. (4) Single Firebase project; pre-merge testing on the Emulator Suite. Any item that weakens one is a blocking defect — refuse and cite the invariant.
- **`onPrimary` is INK `#2A211B` (dark `#1A1510`), never white.** White on marigold measures ≈ 2.5:1 and FAILS WCAG 2.1 AA; the Haldi ink is 5.6:1 (AA). A white-on-marigold foreground (FAB glyph, primary-button label, icon on a marigold fill) is a defect and must fail the contrast gate (DC-01 AC #3).
- **Scope is the foundation ONLY.** Migrate tokens + type + the `OBTColors` extension + `OBTText` helpers + radius/shadow/motion tokens, with their tests. Do **not** convert any screen and do **not** restyle the six `OBT*` widgets here — that is **DC-02** (the next prompt). If an agent proposes converting a screen "while we're here," decline and file it as DC-02/DC-03.
- **Fonts.** Confirm the pinned `google_fonts` exposes `bricolageGrotesque` and `hankenGrotesk`; if not, bundle the `.ttf` fallback per `03-foundation-plan.md` §3.1. `google_fonts` is pure-Dart, so **no `ios/Podfile.lock` change** is expected (do not run `pod install --repo-update` unless a *native* plugin is actually added).
- **Tooling.** This repo is fvm-pinned: run `fvm flutter analyze lib test`, `fvm flutter test`, and `dart format .` (CI gates on `dart format --set-exit-if-changed .`). Commit with `fvm exec git commit` and push with `fvm exec git push` (bare `dart`/`flutter` fail under the fvm SDK in the lefthook hooks).
