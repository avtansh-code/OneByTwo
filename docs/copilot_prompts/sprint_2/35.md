## 2. Numbering / CI title-lint gotcha

The PR title lint (`.github/workflows/pr.yml`) enforces `^(feat|fix|chore|docs|test|refactor|ci|build)(\([a-z0-9_-]+\))?!?: .{1,72}$` — a single-token scope (no commas) and subject <= 72 chars. Keep the title ASCII (avoid the em-dash; the byte-count can surprise the `.{1,72}` check). Suggested title (<= 72 chars): `test(coverage): SC1-SC4, INV2 share-sheet, RT2 CI timing, PY3 harness`. Branch: `test/sprint-2-test-closeout` (repo convention: type-prefixed kebab). Commit with **`fvm exec git commit`** and push with **`fvm exec git push`** (the fvm-pinned SDK; bare `dart`/`flutter` fail under the hooks). The pre-push scoped coverage gate keys on touched `lib/features/**` — adding tests without touching `lib/` leaves it a no-op, but `flutter analyze` still runs on the new test files, so keep them analysis-clean.
