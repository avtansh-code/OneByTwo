       5. **Rate-limit pre-check.** Read `_rateLimits/{senderUid}/sends/{recipientUid}`. If `exists && now - lastSentAt < 24h`, throw `RATE_LIMITED` with `nextAllowedAtIso = lastSentAt + 24h`.
